# Third-party provenance

- **OpenZeppelin Contracts v5.2.0**, MIT, already vendored under `lib/openzeppelin-contracts/contracts/`. Existing license/provenance remain unchanged. Application imports Ownable/Ownable2Step, ReentrancyGuard, SafeERC20, SafeCast and standard ERC20 interfaces.
- **forge-std v1.9.7**, MIT/Apache-2.0, already vendored under `lib/forge-std/src/`. Used only for offline tests.
- **LayerZero ABI definitions**, drawn from the verified Ethereum IMD / Base adapter's `IOFT.sol`, `ILayerZeroEndpointV2.sol` and compose codec definitions. `src/bridge/IMDBridge.sol` is the minimal ABI subset with unchanged tuple layout, not a copied bridge implementation. Fixed option serialization was checked against official OptionsBuilder/ExecutorOptions documentation and actual OFT runtime behavior; see `docs/verification.md`. No external package, dynamic linkage or submodule was added.
- **Runtime fixtures**, byte-for-byte copies of the verified deployed Ethereum token, Base token and Base adapter, used only as test/evidence data with fresh local storage. Provenance, deployed runtime hashes and source declarations are in `docs/evidence/`. Upstream production token/adapter source licensing is separate from the application's MIT license; no unlicensed token implementation is copied into application source. The obsolete NFT fixture was removed.

The supplied pinned security checklist informed the review; it is not a dependency. No website, art, key, wallet configuration, live account state, replacement token or external credential is included. All added build inputs are ordinary repository files and compile without network access.

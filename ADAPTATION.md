# EVERLIGHT GARDEN adaptation

This is a contracts-only replacement of the imported garden's obsolete entitlement/economic paths. Existing build configuration and dependencies were not modified. No `.git`, `.github`, `.env`, `node_modules`, legacy deployed contract or wallet was changed. No token, NFT, pool, proxy, website, deployment transaction or real-fund test purchase was introduced.

## Imported audit disposition

The imported source and tests were read before implementation. The original 82-test suite passed with the assignment's seed. The pinned economics proof was run separately against the original code and failed as predicted: **1.4e18 != 1.1e18** owner-withdrawable on two candles, and **0.5e18 != 0.3e18** ecosystem rate. The passing legacy suite encoded behavior that this brief explicitly rejects; it was not evidence of compliance with the new economics.

## Deployment boundary and remaining blockers

`WishGarden(address owner_)` is the only Ethereum launch application and has a factory-safe nonpayable static constructor, with no dependency calls. It starts disabled. `EverlightBurnReceiver(address owner_, address ethereumGarden_)` is a later **Base** deployment outside the Ethereum manifest. Rates are constants; application bridge configuration freezes on activation. Owner setup, Base source/receiver verification, endpoint defaults/security, native fees, token restrictions/collateral and authenticated readiness are mandatory; see `docs/deployment.md`.

Live reads unexpectedly label the supplied Base token “Fren Pet”, but verify its exact address and official bridge pairing. This is disclosed rather than silently replacing the requester-specified asset. No missing runtime/account credentials were solicited. No `.imd-blocked.json` is needed: the brief explicitly permits owner-settable later receiver/evidence and a disabled Ethereum launch. GitHub publication, source commit and Ethereum address are later network outputs, not fabricated in this contribution. Independent network audit and deployment approval remain separate from local author/model review.
